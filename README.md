# 🏠 House Price Prediction

A Machine Learning project to predict Boston house prices using Linear Regression.

## 📌 About

This project uses the Boston Housing dataset to analyze how different 
factors like number of rooms, crime rate, and highway accessibility 
affect house prices. A Linear Regression model is trained to predict prices.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## 📂 Project Structure

- `notebooks/` - Jupyter notebook with full analysis
- `scripts/` - Individual Python scripts for different analyses

## 📊 What's Inside

- Data exploration and visualization
- Correlation heatmap
- Price vs Rooms analysis
- Highway accessibility impact
- Linear Regression model

   git clone https://github.com/Bhuvan110/house-price-prediction.git
